# JD Collector — 骨架验证版

## 目录结构

```
jd_collector/
├── app.py                # PyWebView 主程序
├── requirements.txt      # 依赖
├── jd_collector.spec     # PyInstaller 打包配置
├── README.md
└── ui/
    ├── index.html        # 主界面
    ├── style.css         # 样式
    └── app.js            # 前端逻辑
```

---

## 第一步：安装依赖

```bash
cd ~/Downloads/jd_collector
/usr/local/bin/python3.10 -m venv .venv
source .venv/bin/activate
pip install pywebview DrissionPage openai python-dotenv pyinstaller
```

---

## 第二步：本地运行验证

```bash
cd ~/Desktop/openclaw-storage/jd_collector
python app.py
```

**预期结果：**
- 弹出一个 960×680 的深色窗口
- 左侧配置面板有搜索词、城市、行业等 Chip 选择器
- 右侧有 Log 区域
- 设置页可以填 API Key、检测 Safari 设置
- 点击「开始采集」会输出骨架提示 log（还没接实际采集逻辑）

## 第三步：打包验证

```bash
cd ~/Desktop/openclaw-storage/jd_collector

# 如果没有 icon，先注释掉 spec 里的 icon 行：
# icon='assets/icon.icns'  →  # icon='assets/icon.icns'

pyinstaller jd_collector.spec
```

打包完成后：
```
dist/
└── JD Collector.app    ← 双击这个
```

**首次打开被拦截？**
右键 → 打开 → 弹窗中点「打开」→ 之后正常双击即可

## 常见问题

**pywebview 安装报错？**
```bash
pip install pywebview --upgrade
```

**打包时 icon 找不到？**
注释掉 spec 文件里两处 `icon='assets/icon.icns'` 即可，图标后续再做。

**打包后闪退？**
```bash
# 改用调试模式打包查看错误
# 修改 spec 里：console=True
pyinstaller jd_collector.spec --clean
# 运行生成的 .app，终端会显示错误信息
```
