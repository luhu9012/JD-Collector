# JD Collector

JD Collector 是一个基于 Python 的桌面工具，用于在本地已登录的 Chrome / Chromium 浏览器中抓取招聘信息，并将结果导出为便于分析的本地文件。

该项目仅适用于你已获得合法授权、且符合目标网站条款及当地法律法规的使用场景，主要用于本地数据收集、筛选和导出。

## 功能概览

- 支持从招聘平台页面抓取职位列表与详情
- 支持“简便模式”和“详情模式”两种采集方式
- 支持输出：Markdown、JSONL、CSV
- 支持本地保存目录选择和导出日志
- 支持可选的 AI 过滤/辅助处理（例如公司名筛选）
- 适配 macOS 与 Windows 本地运行环境

## 项目结构

- `app.py`：桌面应用主入口
- `core.py`：采集逻辑核心
- `ui/`：前端页面与静态资源
- `requirements.txt`：依赖声明
- `jd_collector.spec`：macOS 打包配置
- `jd_collector_win.spec`：Windows 打包配置
- `scripts/check_dev_tools.sh`：环境检查脚本

## 运行要求

- Python 3.10+
- Chrome / Chromium（已登录并可用）
- 目标网站需满足你当地法律法规、服务条款和授权要求

## 安装依赖

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 运行方式

```bash
python app.py
```

首次打开后，建议：

- 在设置页面确认 Chrome 路径
- 设置调试端口（默认 `9222`）
- 启动 Chrome（以远程调试模式运行）
- 登录目标网站并确认连接成功
- 回到采集页开始抓取

## 配置说明

默认配置保存在：

- macOS / Linux：`~/.jd_collector_config.json`
- Windows：`%USERPROFILE%\.jd_collector_config.json`

常用配置项：

- `chrome_path`
- `chrome_port`
- `save_dir`
- `export_formats`
- `api_key`
- `api_base`
- `model`

默认导出目录：

- macOS：`~/Desktop/jd_collector_output`
- Windows：`%USERPROFILE%\Desktop\jd_collector_output`

## 打包说明

### macOS

在 macOS 上可以使用：

```bash
pyinstaller jd_collector.spec
```

打包目录会生成在 `dist/` 下，通常最终产物为 `.app`。

如果本机缺少 Xcode Command Line Tools，可执行：

```bash
xcode-select --install
```

如果仍无法识别开发者目录，可执行：

```bash
sudo xcode-select --switch /Library/Developer/CommandLineTools
export DEVELOPER_DIR=/Library/Developer/CommandLineTools
```

### Windows 10 / 11

Windows 打包必须在 Windows 环境中执行：

```powershell
pyinstaller jd_collector_win.spec
```

说明：

- PyInstaller 不能在 macOS 上直接产出 Windows 可执行文件
- 需要在真实 Windows 10 / 11 环境完成打包
- Windows 版本通常生成在 `dist\JD Collector\`

## 输出格式

- `jd_data.jsonl`：逐行 JSON 格式，便于追加写入和后续处理
- `jd_data.csv`：CSV 表格输出
- `*.md`：每条岗位对应一份 Markdown 文件
